O dashboard chama GET <URL>?de=AAAA-MM-DD&ate=AAAA-MM-DD (Hoje = hoje; Semana = segunda até hoje; Mês = dia 1 até hoje) e espera um JSON com a lista de SDRs. O formato completo está no arquivo API-RANKING.md, que vai junto. Deixe a URL vazia para voltar ao modo demonstração.
